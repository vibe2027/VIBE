## 📝 Key Decisions

### Technology Choices

| Feature | Decision | Rationale |
|---------|----------|-----------|
| Real-time Sync | OT (Operational Transform) | Proven conflict resolution, simpler than CRDT |
| Search | Elasticsearch | Mature, powerful, community support |
| Recommendations | Hybrid Algorithm | Combines collaborative + content-based |
| Mobile | React Native | Code sharing, faster time-to-market |
| Video | WebRTC | Open standard, no vendor lock-in |
| Payments | Stripe Connect | Creator-friendly, transparent payouts |
| Moderation | OpenAI API | SOTA for content classification |

### Privacy & Safety

- All collaboration data encrypted in transit (TLS)
- Video recordings require participant consent
- Moderation appeals process ensures fairness
- Monetization transparent (creator sees all deductions)
- Payment PCI compliance via Stripe (VIBE never sees cards)

### v1.2.0 Threat Model

| Threat | Mitigation |
|--------|-----------|
| Unauthorized access to video | RLS per salon, encryption |

| Recommendation privacy violation | Aggregate-only data, user consent |

| Payment fraud | Stripe fraud detection + 3D Secure |
