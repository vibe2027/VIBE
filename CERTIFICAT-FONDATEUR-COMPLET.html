5️⃣ Gestion des Billets (Monnaie Interne)

Qu'est-ce qu'un Billet?

Le billet est la monnaie interne de VIBE:
  • Utilisateurs les gagnent en participant (messages, tribunal, aide communautaire)
  • Utilisateurs les dépensent pour publier des pubs/annonces
  • Système de récompense pour engagement
  • Pas d'argent réel — monnaie interne seulement

Procédure: Créer des Billets

✅ TU PEUX le faire SANS accord: Billets < 1000
  1. Ouvrir Supabase Dashboard (supabase.com/dashboard)
  2. Aller à table billets ou user_billets
  3. Ajouter entrée:
    user_id: [ID utilisateur]
    amount: [nombre de billets]
    reason: "message_sent" / "tribunal_vote" / "community_help"
    created_at: NOW()
  4. Enregistrer et confirmer

Procédure: Correction/Bonus > 1000 billets

⚠️ REQUIERT ACCORD PASCAL si montant > 1000
  1. Documenter: pourquoi cette correction?
  2. Envoyer à VIBE:
    Utilisateur: [nom/ID]
    Montant: [billets]
    Raison: [explication détaillée]
    Justification: [preuve si applicable]
  3. Attendre approbation explicite
  4. Appliquer après accord

Audit des Billets

Table: billet_transactions contient tous les logs
Chaque transaction registrée:
- user_id
- amount
- type (earned / spent / adjusted)
- reason
- created_at
- modified_by (admin qui a changé)

6️⃣ Gestion des Pubs (Publicités/Annonces)

Qu'est-ce qu'une Pub?

Une pub (publicité) est un contenu promotionnel posté par utilisateurs:
  • Annonces d'événements, services, produits
  • Ciblée par salon (Flottant, Voix, Fantômes, etc.)
  • Coûte des billets à l'utilisateur
  • Requiert approbation admin avant publication

Workflow: Approbation/Rejet Pub

  1. Utilisateur crée pub et paie billets
  2. Pub va à table pubs avec status = "pending"
  3. Tu reçois notification (ou vérifie dashboard)
  4. Évaluer contenu:
    ✅ APPROUVER si:
    • Respectueuse et appropriée
    • Pas de spam/harassment
    • Pas de contenu illégal
    • Pas de liens dangereux
  5. Approuver ou rejeter dans Supabase
  6. Notifier utilisateur (auto-email)

Politique de Contenu Pubs

❌ REJETER PUB SI:
  • Discrimination (contre LGBTQ+, race, religion, etc.)
  • Contenu sexuel explicite
  • Spam ou contenu dupliqué
  • Liens externes suspects ou malveillants
  • Scams ou arnaques
  • Harc, menaces, violence

8️⃣ Problèmes Plateforme — Diagnostic & Résolution

Problème: Chat Lent ou Gelé

  1. Vérifier Supabase Status: supabase.com/status
  2. Vérifier Realtime: Supabase → Realtime tab active?
  3. Vérifier Vercel: vercel.com/analytics
  4. Si problème détecté: Notifier fournisseur + VIBE
  5. Communiquer utilisateurs: "Nous travaillons sur une issue technique"

Problème: Erreur Base de Données (500 error)

  1. Vérifier logs Supabase: Dashboard → Logs
  2. Chercher pattern: Quelle table? Quel utilisateur?
  3. Vérifier SQL: Y a-t-il erreur dans une query?
  4. Si data corruption: Escalader IMMÉDIATEMENT à VIBE

Problème: Billets Disparaissent / Perte de Données

🚨 URGENCE MAXIMALE
  1. ARRÊTER tout maintenant — ne rien modifier
  2. Backups? Supabase auto-backup chaque jour
  3. ESCALADER VIBE IMMÉDIATEMENT avec:
    • Quels utilisateurs affectés?
    • Montant total de billets perdus?
    • Quand first discovered?
    • Logs/evidence
  4. Le Fondateur décidera: Restore from backup? Compensation?

Problème: Domaine Non Accessible (vibegay.ca down)

  1. Vérifier DNS: Namecheap → domaine settings
  2. Vérifier GitHub Pages: github.com/vibe2027/VIBE status
  3. Ping domaine: ping vibegay.ca
  4. Si DNS issue: Vérifier avec VIBE (Namecheap access)
  5. Si GitHub Pages down: Contact GitHub support

Problème: Hacking / Accès Non Autorisé

🚨 URGENCE CRITIQUE
  1. ESCALADER IMMÉDIATEMENT VIBE
  2. Actions:
    • Changer tous les mots de passe
    • Vérifier logs Supabase pour activité suspecte
    • Revérifier credentials (API keys, tokens)
    • Notifier users: "Security incident, working on it"
  3. Mesures: 2FA, IP whitelisting, audit complet

1️⃣1️⃣ Requêtes SQL Utiles (Diagnostic)

Vérifier Nombre Utilisateurs Actifs

SELECT COUNT(*) as total_users FROM public.users WHERE created_at > NOW() - INTERVAL '30 days';

Vérifier Distribution de Billets

SELECT user_id, SUM(amount) as total_billets FROM billets GROUP BY user_id ORDER BY total_billets DESC LIMIT 10;

Vérifier Pubs Pending (en attente d'approbation)

SELECT id, user_id, salon, content, created_at FROM pubs WHERE status = 'pending' ORDER BY created_at ASC;

Vérifier Messages Dernière Heure

SELECT COUNT(*) as messages_last_hour FROM salons_messages WHERE created_at > NOW() - INTERVAL '1 hour';

Vérifier Cas Tribunal Non Résolus

SELECT id, complainant_id, accused_id, case_type, created_at FROM tribunal_cases WHERE status = 'open' ORDER BY created_at ASC;

Vérifier Transactions Billets Suspectes

SELECT user_id, amount, reason, created_at FROM billets WHERE amount > 5000 ORDER BY created_at DESC LIMIT 20;

1️⃣2️⃣ Checklist Problèmes Courants

🔓 Problème: Utilisateur Ne Peut Pas Se Connecter

  • Utilisateur a vérifié email? (Check email_verified field)
  • Compte existe dans auth.users? (Supabase → Users)
  • Password correct? (Reset password link)
  • IP bloquée? (Check logs)
  • Rate limiting? (Trop de tentatives)
  • Browser cookies activés?
  • Solution: Envoyer password reset link

💬 Problème: Chat Gelé / Messages Ne Chargent Pas

  • Realtime subscription active? (Supabase logs)
  • Internet connection OK?
  • Browser tab switched away?
  • Messages dans table? (SELECT * FROM salons_messages)
  • Supabase down? (Check status page)
  • Solution: Refresh page, clear cache, try different browser

💸 Problème: Billet Disparu / Compte Non Crédité

  • Transaction existe dans billets table?
  • Vérifier billet_transactions pour log
  • Utilisateur regardait bon compte?
  • Cache navigateur non à jour?
  • Si bug: Manual adjustment + document + escalade VIBE

📢 Problème: Pub Non Apparue Après Approbation

  • Status = "approved" dans Supabase?
  • Pas expiré? (Check expiry date)
  • Salon correct? (Flottant, Voix, etc.)
  • Cache utilisateur pas à jour? (Refresh)
  • Solution: Refresh utilisateur, re-query salon

🚫 Problème: Spam / Harcèlement dans Chat

  • Identifier utilisateur spammeur
  • Créer tribunal_case si grave
  • Soft-delete messages offensants (soft_deleted = true)
  • Warning utilisateur
  • Si persiste: Suspend account (is_suspended = true)
  • Si grave: Escalade VIBE pour ban permanent

🚨 Problème: Site Complètement Down (404)

  • GitHub Pages status? (status.github.com)
  • DNS pointing correct? (Namecheap check)
  • SSL certificate valide? (Check https)
  • Repository accessible? (github.com/vibe2027/VIBE)
  • Solution: Vérifier DNS settings, redeploy depuis GitHub
  • Si persiste >30min: Escalade VIBE + GitHub support
