🚀 VIBE Production Setup

Complete this checklist to get your site online with 24/7 monitoring

📋 Step 1: Get Your Secrets (5 min)
Get Supabase Keys
Go to Supabase Dashboard → Settings → API
Copy: Project URL, anon key, service_role key
5 min
Get Stripe Keys
Go to Stripe Dashboard → Developers → API Keys
Copy: Public key (pk_), Secret key (sk_), Webhook secret (whsec_)
Also copy 2 Price IDs from Products
5 min
🌐 Step 2: Deploy on Netlify (10 min)
Create Netlify Site
Go to Netlify Dashboard → "New site from Git"
Select: GitHub → vibe2027/VIBE → Deploy
5 min
Add 10 Environment Variables
Settings → Build & deploy → Environment
Add all 10 variables from your Supabase & Stripe keys
See COPY-PASTE-GUIDE.md for exact values
3 min
Redeploy & Wait for Green ✅
Deployments → Latest → Click "Redeploy"
Wait for green checkmark (2-3 minutes)
5 min
Test Site Works
Run: curl https://vibegay.ca/api/health
Should return: "status":"ok"
1 min
📡 Step 3: Setup Monitoring (5 min)
Create UptimeRobot Account
Go to UptimeRobot → Sign Up → Verify Email
2 min
Add Monitor
"Add New Monitor"
URL: https://vibegay.ca/api/health
Interval: 5 minutes
2 min
Add Email Alert
Monitor → Alerts → Email
You'll get email if site goes down
1 min
💬 Step 4: Setup Slack Alerts (5 min)
Create Slack App
Go to Slack Apps → "Create New App" → "From scratch"
Name: VIBE Alerts → Create
2 min
Enable Webhooks & Copy URL
Left sidebar → "Incoming Webhooks" → Toggle ON
"Add New Webhook" → Select channel → Allow
Copy webhook URL (https://hooks.slack.com/...)
2 min
Add to GitHub Secrets
Go to GitHub Settings → Secrets
"New secret" → Name: SLACK_WEBHOOK_URL
Value: [PASTE webhook URL]
1 min
🚄 Step 5: Setup Railway Fallback (15 min)
Deploy on Railway
Go to Railway → "Start Project" → "Deploy from GitHub"
Select: vibe2027/VIBE → Deploy
5 min
Add 10 Environment Variables
Project → Variables
Add same 10 as Netlify
5 min
Test Railway Works
Get Railway URL from Deployments
Run: curl https://[railway-url]/api/health
Save this URL for emergencies!
5 min

✅ Setup Complete!

Your site now has:

  • 🟢 Netlify - Primary hosting (LIVE NOW)
  • 📡 UptimeRobot - Monitors every 5 min
  • 💬 Slack Alerts - Instant notifications
  • 🚀 Railway - Fallback if Netlify dies
  • ⚙️ GitHub Actions - 24/7 healthchecks
