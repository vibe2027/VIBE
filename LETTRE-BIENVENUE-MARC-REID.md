Cher Marc,

C'est avec une grande satisfaction et confiance que je vous accueille officiellement comme **Directeur des Opérations** au sein de VIBE.

## 🌊 Notre Mission Commune

VIBE n'est pas qu'une plateforme technologique. C'est un refuge, un espace d'authenticité pour la communauté LGBTQ+ mondiale. Nous avons construit cela avec **Humilité Totale**, **Respect**, et **Authenticité** comme valeurs fondamentales. Votre rôle est crucial pour maintenir ces principes au jour le jour.

## 📋 Vos Responsabilités Officielles

En tant que Directeur des Opérations, vous gérerez:

### ✅ Ce que vous POUVEZ décider et faire de manière indépendante:

1. **Gestion des Billets (Monnaie Interne)**
   - Émettre des billets aux utilisateurs
   - Corriger des erreurs de billets (< 1000 billets)
   - Auditer les transactions
   - Documenter toutes les corrections

2. **Gestion des Pubs (Publicités/Annonces)**
   - Approuver les pubs conformes
   - Rejeter les pubs non appropriées
   - Appliquer notre politique de contenu
   - Documenter les raisons de rejet

3. **Support Clientèle**
   - Répondre aux questions des utilisateurs
   - Fournir assistance technique
   - Résoudre les problèmes simples
   - Créer des tickets pour problèmes complexes

4. **Diagnostic de Plateforme**
   - Vérifier les logs et tableaux de bord
   - Identifier les problèmes techniques
   - Documenter les bugs
   - Proposer des solutions

5. **Escalade Appropriée**
   - Déterminer quand un problème me nécessite
   - Préparer les informations pour escalade
   - Suivre les procédures d'escalade

### ❌ Ce que vous NE POUVEZ PAS faire sans mon accord explicite:

1. **Modifications Plateforme**
   - Aucun changement de code
   - Aucune modification de base de données (sauf via Supabase interface autorisée)
   - Aucune modification de configuration serveur
   - Aucun déploiement

2. **Décisions Financières**
   - Aucune approbation de paiement
   - Aucun remboursement
   - Aucune transaction d'argent réel

3. **Corrections > 1000 Billets**
   - Toute correction majeure requiert mon approbation

4. **Décisions Stratégiques**
   - Politique nouvelle
   - Changement de direction
   - Partenariats externes
   - Prises de décision stratégiques

5. **Sécurité & Données Sensibles**
   - Aucun accès à credentials
   - Aucune modification de RLS policies
   - Aucune suppression de données permanente

## 🎯 Vos Objectifs Primaires

1. **Assurer la Stabilité Quotidienne**
   - La plateforme fonctionne sans interruption
   - Les utilisateurs reçoivent support rapide
   - Les problèmes sont diagnostiqués rapidement

2. **Maintenir la Qualité Communautaire**
   - Rejeter les pubs offensantes
   - Documenter les violations
   - Protéger nos valeurs LGBTQ+

3. **Vigilance & Monitoring**
   - Vérifier régulièrement les tableaux de bord
   - Identifier les anomalies
   - Signaler les problèmes immédiatement

4. **Documentation Complète**
   - Tous les changements documentés
   - Tous les problèmes loggés
   - Audit trail complet

## 📞 Quand M'Escalader (Procédures)

### 🚨 **CRITIQUE** — Escalade IMMÉDIATE:

- **Hacking ou accès non autorisé** — Sécurité compromise
- **Perte massive de données** — Billets perdus, messages effacés
- **Domaine/site complètement down** — > 1h sans service
- **Accusation légale ou menace juridique** — Protection légale requise
- **Issue financière** — Fraude, paiements perdus

**Template pour escalade critique:**
```
Sujet: 🚨 URGENT - [Type Problème]

Pascal,

Issue critique:
• Description: [Quoi exactement?]
• Scope: [Combien d'utilisateurs?]
• Timeline: [Depuis quand?]
• Status: [En cours ou résolu?]
• Actions: [Qu'ai-je fait?]

Besoin approbation pour: [Quoi?]

Marc
```

### ⚠️ **ÉLEVÉ** — Escalade dans l'heure:

- Corrections > 1000 billets
- Rejet pub avec légalité questionnable
- Utilisateur escalade avec menace
- Problème non résolu après 2h
- Question de politique nouvelle

### ℹ️ **INFO** — Rapport fin de journée:

- Résumé des actions prises
- Pubs approuvées/rejetées
- Problèmes diagnostiqués
- Statistiques utilisateurs
