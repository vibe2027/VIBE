# VIBE — Pricing & Access Model

## 1. Objectif
Le modèle de revenus de VIBE doit être agressif, clair et crédible, tout en restant accessible à la croissance.

## 2. Tiers

### Free
- accès limité
- Ange Gardien disponible
- Salon Flottant jusqu'à 25 km
- musique du salon
- chat basique

### Founder Pass
Prix : 199 $ CAD / an
Places : 500 limitées

Avantages :
- accès total à toutes les fonctionnalités
- accès illimité aux salons et filtres premium
- mode fantôme
- salon de la voix
- bonus de diffusion / boosts
- badge founder
- priorité support
- immunité au tribunal communautaire
- accès anticipé aux nouvelles fonctionnalités

### Premium Standard
Prix : 149 $ CAD / an

Avantages :
- accès complet à toutes les fonctionnalités premium
- support standard
- sans badge founder
- sans immunité au tribunal

### Extras à la carte
- Mode Fantôme : 4,99 $ / mois ou 39,99 $ / an
- Salon de la Voix : 4,99 $ / mois ou 39,99 $ / an
- DJ Live Access : 2,99 $ / mois ou 19,99 $ / an
- Filtres compatibilité premium : 3,99 $ / mois ou 29,99 $ / an
- Distance illimitée : 7,99 $ / mois ou 59,99 $ / an
- 3 Anges supplémentaires : 9,99 $ / mois ou 79,99 $ / an

### Boosts
- 1 semaine : 4,99 $
- 1 mois : 9,99 $
- 3 mois : 19,99 $
- 6 mois : 34,99 $
- 1 an : 49,99 $

## 3. Stratégie de lancement
### Phase 1 : Founder Burst
- objectif : 500 founder passes vendus
- système d'urgence : spots limités
- message : "prix augmente après 500"
- résultat attendu : cash rapide + social proof

### Phase 2 : Premium Conversion
- free tier pour acquisition
- conversion via extras
- premium standard après 500

### Phase 3 : Scaling
- mettre le premium standard comme offre de croissance
- augmenter la valeur perçue avec nouvelles expériences
- optimiser les extras selon usage

## 4. Positionnement
Le prix est élevé parce que VIBE n'est pas simplement une application de rencontre : c'est un espace immersif, sécuritaire, premium, social et communautaire. La valeur est perçue en fonction des fonctionnalités, de la sécurité, et du statut social.

## 5. Recommandation
VIBE doit être poussée comme un produit premium, avec :
- free tier utile
- pricing premium raisonnable
- message d'exclusivité sur le Founder Pass
- extras pour augmenter le revenu moyen par utilisateur
