# VIBE — AI Marketing Automation

## Objectif
Automatiser la présence sociale de VIBE sur les plateformes, chaque heure, avec contenu propre, ciblé, et orienté conversion.

## Flux de contenu
### 1. Post de présentation
- carousel/vidéo court sur fonctionnalité VIBE
- CTA vers la page de vente ou vers un waitlist

### 2. Story / Reels / TikTok / Shorts
- démonstration d'un salon flottant
- démonstration du mode fantôme
- démonstration de l'Ange Gardien
- démonstration du salon de la voix

### 3. Social proof
- fondation / early users / founder stickers
- commentaires "j'ai rejoint"
- statistiques en live

### 4. Urgence / scarcity
- "Seulement 500 founder passes disponibles"
- "Le prix augmente après 500"

## Fréquence
- 1 publication toutes les 2 à 3 heures sur les plateformes actives
- stories à plusieurs moments de la journée
- un résumé quotidien à 13h00

## Source de contenu
L'AI peut produire :
- copies marketing courtes
- scripts pour vidéos
- hooks de conversion
- descriptions de salon
- messages de sécurité / fondement / valeurs

## Analyse quotidienne
Le système AI doit produire un briefing quotidien à 13h00 avec :
- nouveaux inscrit·es
- nouveaux founder passes
- revenue
- bugs
- faux profils détectés
- tendances de comportement
- recommandations

## Règles de sécurité
- aucun contenu ne doit être publié sans validation interne si sa portée est critique
- les contenus sur les droits, protection ou abus doivent être lus par un humain avant publication
- tout incident sérieux doit modifier automatiquement le statut d'alerte

## Pipeline de sortie
- création de texte marketing
- génération d'image / visuel
- publication via API ou via outil de gestion social
- tracking d'engagement
- synthèse d'impact dans le dashboard
